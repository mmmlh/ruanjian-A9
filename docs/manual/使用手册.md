# 智能家居设备控制系统 — 使用手册

> 基于 OpenHarmony 的家居设备控制系统 | 第十五届软件杯 A9 赛题

---

## 一、系统概述

本系统是一个基于 OpenHarmony 操作系统的智能家居设备控制平台，支持对灯光、空调、门禁等设备的远程控制和智能联动。

**四大核心模块**：
- 🏠 **控制中心** — 设备总览 + 房间管理 + 场景联动
- 💡 **照明中心** — 灯光开关 + 亮度色温调节 + 人体感应
- 🌡️ **温湿度中心** — 环境监测 + 多品牌空调控制
- 🔒 **智能门禁** — 远程开锁/上锁 + 安全认证

## 三、功能操作说明

### 3.1 登录与注册

#### 登录

1. 打开 APP，进入登录页面
2. 输入用户名和密码
3. 点击 **登 录** 按钮
4. 登录成功后自动跳转到仪表盘

> **提示**：如登录失败，会显示红色错误信息。检查用户名密码是否正确。

#### 注册

1. 在登录页点击 **立即注册**
2. 输入用户名、密码（至少6位）、确认密码
3. 点击 **注 册** 按钮
4. 注册成功后自动登录并跳转

### 3.2 控制中心（仪表盘）

仪表盘是系统的总览页面，展示所有房间和设备状态。

**操作步骤**：

1. **查看设备状态**：进入仪表盘，所有设备以卡片形式展示
   - 绿色圆点/文字表示正常在线
   - 每个卡片显示设备名称和实时状态
2. **切换房间**：点击顶部的房间标签（全部/客厅/卧室）筛选设备
3. **查看温湿度**：顶部温湿度卡片实时显示当前值
4. **进入设备控制**：点击设备卡片跳转到对应控制页面
5. **底部导航**：使用底部四个 Tab 切换模块

**连接状态**：
- 🟢 已连接 — WebSocket 连接正常，数据实时推送
- 🔴 断开 — 连接异常，会自动尝试重连（每5秒）

### 3.3 照明控制

**操作步骤**：

1. 从仪表盘点击灯光设备卡片，或在底部导航点击 **照明**
2. **开关灯**：点击中央大圆按钮
   - 开启状态：黄色圆，显示"已开启"
   - 关闭状态：灰色圆，显示"已关闭"
3. **调节亮度**：拖动亮度滑块（0-100%），实时生效
4. **切换色温**：点击底部色温按钮
   - 🔥 **暖光** — 适合休息、睡前
   - ❄️ **冷光** — 适合工作、阅读
   - 🌿 **自然** — 接近自然光
5. **切换灯具**（如有多个）：点击顶部的灯具名称标签

### 3.4 空调控制

**操作步骤**：

1. 从仪表盘点击空调设备卡片，或在底部导航点击 **空调**
2. **开关空调**：点击中央 **开启空调/关闭空调** 按钮
3. **调节温度**：
   - 点击 **-** 降低 1°C
   - 点击 **+** 升高 1°C
   - 范围：16°C ~ 30°C
4. **切换模式**：点击下方模式按钮
   - ❄️ **制冷** — 夏天降温
   - 🔥 **制热** — 冬天取暖
   - 💧 **除湿** — 潮湿天气
   - 🌀 **送风** — 仅风扇
   - 🔄 **自动** — 智能调温
5. **调节风速**：点击风速按钮（自动/低速/中速/高速）
6. **品牌显示**：右上角显示当前空调品牌标签

### 3.5 智能门禁

**操作步骤**：

1. 从仪表盘点击门禁设备卡片，或在底部导航点击 **门禁**
2. **查看状态**：
   - 🔒 绿色圆 + "已锁定" — 门已锁
   - 🔓 橙色圆 + "已解锁" — 门已开
3. **开锁**：点击 **🔓 开 锁** 按钮
   - 系统会发送加密认证码
   - 成功后显示"开锁成功"
4. **上锁**：点击 **🔒 上 锁** 按钮
   - 成功后显示"上锁成功"
5. **安全提示**：页面底部显示加密传输状态

> **注意**：门禁操作通过 AES-256 + JWT 加密传输，确保安全。

## 四、智能联动规则

系统预置了四条自动联动规则：

### 4.1 人来开灯 🌟

- **触发条件**：人体感应传感器检测到有人 + 灯处于关闭状态
- **执行动作**：自动开灯（亮度 80%）
- **应用场景**：晚上回家自动亮灯

### 4.2 人走关灯 💤

- **触发条件**：人体感应传感器检测到无人 + 灯处于开启状态
- **执行动作**：自动关灯
- **应用场景**：离开房间自动节能

### 4.3 高温自动制冷 🔥

- **触发条件**：温度传感器数值 > 28°C + 空调处于关闭状态
- **执行动作**：自动开启空调（制冷模式，26°C）
- **应用场景**：夏天室温过高自动降温

### 4.4 高湿自动除湿 💧

- **触发条件**：湿度传感器数值 > 80% + 空调处于关闭状态
- **执行动作**：自动开启空调（除湿模式）
- **应用场景**：梅雨季节自动除湿

> **提示**：规则引擎在云端运行，无需手动干预。可通过 API 动态配置新规则。

## 六、安全机制

### 6.1 三层加密体系

```
┌──────────────────────────────────┐
│  1. 传输层：TLS/SSL 加密通道      │
│     HTTPS + MQTT over TLS        │
├──────────────────────────────────┤
│  2. 身份层：JWT Token 认证        │
│     24h 过期 + HS256 签名         │
├──────────────────────────────────┤
│  3. 数据层：AES-256-CBC 加密      │
│     随机密钥 + 随机 IV + PKCS7   │
└──────────────────────────────────┘
```

### 6.2 安全特性

- ✅ 密码使用 bcrypt 哈希存储，不可逆
- ✅ JWT Token 包含 AES 密钥，认证即授权
- ✅ 门禁操作需验证认证码
- ✅ 所有 API（除登录/注册）都需要 Bearer Token
- ✅ 操作日志完整记录（谁在何时做了什么）

## 七、常见问题

### Q1: APP 连接不上后端？

1. 检查后端服务是否启动：`docker compose ps`
2. 检查 `ApiClient.ets` 中的 `BASE_URL` 是否指向正确地址
3. 检查防火墙是否放行 8000 端口

### Q2: 设备状态不更新？

1. 检查模拟器容器是否运行：`docker compose logs simulators`
2. 检查 MQTT Broker 状态：`docker compose logs mqtt`
3. 确认 WebSocket 连接状态（仪表盘右上角）

### Q3: 如何重置数据库？

```bash
# 删除数据库文件，重启后自动重建
rm smart-home-A9/cloud/data/smart_home.db
docker compose restart backend
```

### Q4: 如何添加新设备？

1. 通过 API: `POST /api/devices` (需要提供 room_id, type, name, mqtt_topic)
2. 或直接在数据库中插入记录
3. 在 `simulator_manager.py` 中添加对应模拟器实例

### Q5: 如何修改服务器地址？

编辑 `smart-home-A9/openharmony/entry/src/main/ets/common/ApiClient.ets`：
```typescript
const BASE_URL = 'http://<你的服务器IP>:8000'
```

## 八、部署到阿里云

### 8.1 使用部署脚本

```bash
# 方式1: Shell 脚本
# 1. 上传代码到服务器
scp -r smart-home-A9/cloud root@<服务器IP>:/opt/smart-home-A9/
# 2. SSH 登录并执行
ssh root@<服务器IP>
cd /opt/smart-home-A9/cloud
bash deploy.sh

# 方式2: Python 自动部署
export SMART_HOME_SERVER="<服务器IP>"
export SMART_HOME_PASS="<密码>"
python smart-home-A9/deploy_remote.py
```

### 8.2 手动部署

```bash
# 1. 安装 Docker
curl -fsSL https://get.docker.com | sh

# 2. 上传项目文件
scp -r cloud/ root@<IP>:/opt/smart-home-A9/

# 3. 启动服务
cd /opt/smart-home-A9/cloud
docker compose up -d

# 4. 验证
curl http://localhost:8000/api/health
```

### 8.3 配置 Nginx

部署后通过 Nginx 反向代理对外提供服务：
- HTTP: http://\<服务器IP\>
- API: http://\<服务器IP\>/api/\*
- Swagger: http://\<服务器IP\>/docs

## 附录：MQTT 调试指南

使用 MQTTX 桌面客户端调试设备通信：

1. 下载 MQTTX：https://mqttx.app/
2. 新建连接：
   - Host: localhost
   - Port: 1883
3. 订阅主题：`home/#`
4. 查看实时消息：
   - 传感器数据：`home/livingroom/temperature_sensor/sensor`
   - 设备状态：`home/livingroom/light/status`
5. 手动发送控制指令：
   - Topic: `home/livingroom/light/command`
   - Payload: `{"action": "on", "brightness": 80}`
