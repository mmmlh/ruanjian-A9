# 登录页服务器配置移除设计

## 目标

移除 OpenHarmony 登录页中用于展开、编辑服务器地址的界面与交互，让用户不能在登录页修改服务端地址。

## 范围

- 删除 `LoginPage.ets` 的服务器配置展开控件、地址输入框、提示信息及其页面状态。
- 登录操作不再调用 `setBaseUrl`。
- 保留应用初始化时从本地偏好读取服务器地址、无记录时使用 `DEFAULT_SERVER_URL` 的行为。

## 不在范围内

- 不修改 `SecureStorage.ets`、`ApiClient.ets` 或桌面卡片的服务器地址读取逻辑。
- 不迁移或清除已保存的服务器地址偏好。
- 不修改服务端部署地址或 API 合约。

## 实施与验证

更新前端配置回归测试，断言登录页不含服务器配置 UI 或 `setBaseUrl` 调用；执行该测试确认默认与持久化地址仍由基础设施层处理。
