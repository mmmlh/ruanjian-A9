# 回家模式全设备启用

## 目标

将预置“回家模式”改为把全屋可控设备设置为明确的到家状态，同时不降低门锁安全性。

## 范围与状态

场景执行时下发 10 个 MQTT 动作：

- 三盏灯开启，亮度为 80%。
- 三台空调开启制冷，温度为 26°C。
- 客厅与书房窗帘打开。
- 卧室加湿器开启，档位为 2、目标湿度为 60%。
- 门锁上锁。

温湿度与人体传感器无需接收开关指令，因此不在场景动作内。

## 数据与兼容性

更新新建数据库的预置场景描述和动作 JSON；启动时也修复现有数据库中仍保留旧版默认动作的“回家模式”预置场景，以便已有部署即时获得新状态。用户创建、改名或修改过动作的场景不受影响。

## 验证

新增后端场景测试，断言回家模式包含全部 10 个可控设备动作及预期参数；运行场景相关测试和完整 Python 测试集。
